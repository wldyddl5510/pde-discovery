# Debiased WSINDy sanity check

Benchmark `VBG`: `u_t = (1) 1 + (0.01) D(2, 0)(u) + (2) u^2 + (-0.5) D(1, 0)(u^2) + (-1) u^3` on grid `(512, 451)`; reference noise `sigma_c = 0.057735`; multipliers `[0.5, 1.0, 2.0, 5.0, 10.0]`; `50` trials per level (root seed 0). Library: `43` terms; `m = (64, 56)`, `s = (12, 11)`, `bump` test functions, rescale `False`; sparse selection `absolute` thresholds in `physical` units.

Methods on identical observations and pilots: **raw** integrates `U^p`; **filtered** integrates `pilot^p`; **debiased** integrates `(1-p) pilot^p + p pilot^(p-1) U` (Section 5 with `u_*` replaced by `U`), so its LHS and linear columns equal the raw ones. The pilot is a box moving average with odd window length `size` on every axis (capped by `2m+1`), boundary `('wrap', 'reflect')`; split `time2` averages each point over the other time-index parity only (2-fold cross-fitting), `checkerboard` over the other index-sum parity, `none` over all points. The data-driven window of the consistency paper (volume rule, prior `tau*`, rounded up to odd) is included per trial.

Restricted OLS uses the true support plus the terms Gaussian noise generates from it (`u` here). Columns show fitted coefficient minus truth; each generated term's header gives the coefficient predicted for raw OLS from the Gaussian moments of the true monomials, and the smallest true coefficient is shown because it dominates `E_inf`, the maximum relative error over the true coefficients. Entries are mean ± sample standard deviation over trials.
